# Como Criar Documentos para o Prompt Hub

Cada documento deve seguir esta estrutura para garantir consistência e facilitar a busca automática.

---

## Formato Padrão

```markdown
# [Título do Documento]

## Resumo
(2-3 linhas explicando o que o documento cobre)

## Regras Fundamentais
- Regra 1: descrição
- Regra 2: descrição
- Regra 3: descrição

## Exemplos Práticos
### Bom exemplo
[explicação do por que é bom]

### Mau exemplo
[explicação do por que é ruim]

## Recomendações por Nicho
| Nicho | Recomendação | Por quê |
|-------|--------------|---------|
| Fintech | ... | ... |
| Saúde | ... | ... |
| Educação | ... | ... |

## Fontes e Referências
- [Link 1](url)
- [Link 2](url)
```

---

## Dicas por Tópico

### Paleta de Cores
- Sempre incluir códigos HEX, RGB e HSL
- Mostrar exemplos visuais (quando possível)
- Listar armadilhas comuns a evitar
- Referenciar WCAG para acessibilidade

### Tipografia
- Fornecer links para download das fontes
- Mostrar exemplos de uso prático
- Explicar métricas técnicas (x-height, ascender, etc.)
- Indicar fontes do Google Fonts quando aplicável

### UI
- Incluir código HTML/CSS de exemplo
- Listar todos os estados (hover, focus, active, disabled)
- Listar checks de validação
- Incluir medidas em pixels/rem

### UX
- Basear-se em pesquisas e estudos
- Fornecer links para fontes acadêmicas
- Incluir casos de uso reais
- Explicar o "por quê" de cada recomendação

---

## Sistema de Busca

Os documentos serão consultados automaticamente pela IA. Para facilitar a busca:

1. **Use headings claros** (`##`, `###`) para estruturar o conteúdo
2. **Inclua palavras-chave** no início do documento
3. **Mantenha a estrutura consistente** entre documentos do mesmo tópico
4. **Separe por nichos** quando relevante (ex: fintech, saúde, educação)

---

## Checklist de Criação

Antes de finalizar um documento, verifique:

- [ ] Resumo claro e objetivo
- [ ] Regras fundamentais numeradas
- [ ] Exemplos práticos (bom e mau)
- [ ] Recomendações por nicho (tabela)
- [ ] Fontes e referências
- [ ] Formatação consistente com outros documentos
